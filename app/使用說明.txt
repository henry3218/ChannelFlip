切換語言保留裝置、互換開關與本次聽感確認；Windows 裝置名稱不翻譯。

直接執行 ChannelFlip.exe。原始碼採用 MIT 授權。
音訊核心已包在同一個 EXE，無須 Equalizer APO、虛擬音效卡、Python 或 Node.js。
使用 Windows x64 的 .NET Framework 4.6.2 以上版本。

1. 選擇要互換的耳機或喇叭。
2. 首次按「設定此裝置」，閱讀影響範圍後按「設定並開啟互換」。
3. 完成 Windows 管理員授權；電腦音訊會短暫中斷，並播放兩聲短音。
4. 設定完成後，使用「左右互換」開關。
5. 分別測試來源左、右聲道。互換開啟時，來源左應從右耳、來源右應從左耳聽到。
6. 兩邊測試完成後，可按「我聽到的左右方向符合」記錄本次聽感。

「設定：開啟」表示已保存開關。
「等待音訊／尚待測試」表示這次設定尚無核心處理或測試證據。
「目前沒有新音訊」表示暫時沒有新處理計數；上次測試與聽感確認會保留，不必因暫停播放重測。
「已偵測到互換處理」來自近期計數，實際左右耳方向仍需聽測。
核心錯誤、裝置離線與無法讀取狀態會有不同提示。
改變裝置或開關、斷線或音訊宿主重啟時，舊的方向確認會失效；關閉程式後不保存聽感紀錄。
可用 Tab 選取控制項、空白鍵切換滑塊開關。支援 Windows 文字大小與螢幕縮放；放大時可捲動至所有操作。

固定裝置：斷線後保留原目標，重連相同端點後恢復顯示。
跟隨系統預設：視窗操作目標跟隨多媒體預設，各裝置的設定獨立保存。
新裝置須先完成設定。關閉視窗後，已接入裝置仍保留開關；下次開啟再解析預設裝置。

進階設定：
• 關閉所有已設定裝置的互換：恢復方向，保留核心與系統設定。
• 重新啟動電腦音訊服務：所有音訊輸出會短暫中斷。
• 移除所有裝置的設定：包含離線裝置；確認清單後還原本程式的變更，並重新啟動音訊服務。

此預覽版音訊核心尚未取得 Microsoft 音訊簽章。
首次啟用需將 DisableProtectedAudioDG 設為 1，作用於整台電腦；
部分要求受保護音訊路徑的 DRM 播放可能受影響。
關閉互換或視窗會保留這項設定，移除時依備份還原。

作用於所選裝置的 Windows 共用模式音效路徑。
ASIO、獨佔模式、RAW、音訊直通及停用音效強化可能繞過處理。
單聲道沒有左右差異，多聲道只交換前方 L/R。
Windows 10 尚未實測。詳細測試範圍見原始碼倉庫的 VALIDATION.md。
